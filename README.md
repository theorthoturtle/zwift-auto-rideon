# Auto Ride On for Zwift

<img src="Windows/icon.png" width="96" align="right" alt="">

Gives Ride Ons automatically while you ride on Zwift. It appears in Zwift as an extra
**KICKR BIKE PRO** controller over Wi-Fi and holds its Ride On button for 3 seconds at a
random moment every 8–10 seconds, with a small always-on-top window to switch it on and off
and see how many riders you've reached.

By Michael B.

| Your computer | Folder | Download |
|---|---|---|
| Windows 10/11 | [`Windows`](Windows) | the newest `zwift-auto-rideon-x.y.z.zip` in that folder |
| macOS 10.15+ | [`MacOS`](MacOS) | the newest `zwift-auto-rideon-mac-x.y.z.zip` in that folder |

Each folder's README has the install steps. Both versions run the same code; only the
launchers and setup differ.
